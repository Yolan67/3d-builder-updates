# 3D Builder – Downloads und Updates

Hier liegen nur die fertigen Windows-Installationsdateien des **3D Builder** (kein Quellcode).

- **Installieren:** unter [Releases](../../releases/latest) die Datei `3D-Builder-Setup.exe` herunterladen und ausführen.
- **Updates:** Das installierte Programm prüft beim Start selbst, ob es hier eine neue Version gibt, und fragt vor der Installation nach.

Windows 10/11 (64 Bit). Das Programm ist nicht digital signiert – Windows zeigt beim ersten Start einen Hinweis („Weitere Informationen“ → „Trotzdem ausführen“).
